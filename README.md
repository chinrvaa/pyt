# Bags x Roblox Growth Engine Site

Hackathon landing page for the Roblox + Bags integration project.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is generated in `dist/`.

## Deploy to GitHub Pages

1. Create a GitHub repo and push this project.
2. In GitHub repository settings, enable Pages and set source to **GitHub Actions**.
3. Push to `main` branch; the included workflow will build and deploy automatically.

## Customize before submission

Update these fields in `src/App.tsx`:

- Project links (`Apply Project`, `GitHub Repo`)
- Contact email and X handle
- Milestones and traction metrics

## Stack

- React + TypeScript + Vite
- GitHub Actions deployment
